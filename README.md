# Paradox: Timeline Incursion, playable demo

A competitive time-travel board game by Rafael Reis Garcia, playable in the browser against AI opponents.

**Play:** https://reisaurafael.github.io/paradox-play/

Travellers race along thirty centuries, secretly allocate dice in a time machine every Hour, and score by returning historical objects to the century they came from. This demo runs the full rules engine and the AI opponents inside your browser; nothing is installed and no account is needed.

About the game, its design and how it was built: https://reisaurafael.github.io/paradoxo-simulator/
